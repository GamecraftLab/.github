# Contributing to Gamecraft Lab projects

Thanks for helping out!

1. **Open an issue first** for anything larger than a small fix, so we can agree on the approach.
2. **Fork, branch, pull request.** Keep pull requests focused on one change.
3. **Match the existing code style** of the project you're changing.
4. **No copyrighted files.** Never commit or link ROMs, BIOS files, firmware, games or paid assets.

Individual projects may have their own `CONTRIBUTING.md` with more details — that one takes precedence.
